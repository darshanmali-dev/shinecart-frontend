# 🛍️ ShineCart Frontend

A modern e-commerce frontend built using **React**. It provides a seamless shopping experience with authentication, cart, payments, and more.

---

# Backend Repo

https://github.com/darshanmali-dev/shinecart-backend

## 🚀 Live Demo

🔗 https://shinecart-frontend.vercel.app

---

## 🛠️ Tech Stack

* React (Vite)
* TypeScript (if used)
* Axios (API calls)
* Tailwind CSS / CSS
* React Router
* Razorpay Integration

---

## ✨ Features

* 🔐 User Authentication (Login/Register)
* 🛍️ Product Browsing
* 🛒 Cart Management
* 💳 Payment Integration (Razorpay)
* 📦 Order Tracking
* ❤️ Wishlist (if implemented)
* 🤖 Chatbot (if implemented)

---

## ⚙️ Environment Variables

Create a `.env` file:

```
VITE_API_URL=https://shinecart-backend-vf0z.onrender.com
```

---

## ▶️ Run Locally

```bash
git clone https://github.com/darshanmali-dev/shinecart-frontend.git
cd shinecart-frontend
npm install
npm run dev
```

---

## 🔗 API Integration

All API calls are handled via a centralized Axios instance.

## 🚀 Deployment
